# Аппликатуры, определитель аккордов, строй, каподастр слушателя, режимы zen — дизайн

Дата: 2026-10-03. Продолжение `2026-09-27-alphatex-tabs-design.md`.

## Цель

- На странице песни — подсказка аккордов: диаграммы всех аккордов песни, у каждого несколько
  аппликатур, их можно листать. На десктопе — колонка справа, на телефоне — полоска; скрывается.
- Автор выбирает удобную аппликатуру из предложенных или рисует свою.
- Строй песни: автор выбирает строй гитары, аппликатуры, табы и звук считаются под него.
- Каподастр слушателя: выбираешь лад — аккорды и табы перестраиваются, звучание то же.
  Подсказка «удобного» каподастра.
- Вкладка «Аккорды»: определитель (натыкал ноты на грифе — видишь название) и поиск
  (название — все аппликатуры) для гитары, баса и укулеле.
- Zen: следующие две строки читаются, режим «аккорды в полосе», пауза с выбором режима,
  прокрутка на паузе и «играть отсюда».

Решения пользователя:

- «Свой аккорд» — это своя аппликатура для обычного аккорда (`Am`), а не аккорд с произвольным
  именем.
- Телефон: полоска карточек под шапкой песни, варианты — стрелками на карточке; тап по аккорду
  в тексте открывает всплывашку с карточкой.
- Десктоп: колонка всегда справа, её можно скрыть.
- Определитель — в новой вкладке «Аккорды» с режимами «Определить» и «Найти».
- Определитель и поиск — гитара, бас, укулеле; панель аккордов в песне — только гитара.
- В сдвинутых строях (полтона ниже, D Standard, Drop C) аккорды пишутся формами, как в
  стандартном строе (Drop D для Drop C); звук сдвигается.
- Слушатель меняет только каподастр, строй всегда авторский.
- Каподастр выше авторского: ноты таба переносятся на другие струны; что не помещается —
  помечается.
- Автор поменял каподастр при готовых аккордах — диалог «Пересчитать / Оставить как написано».
- Удобный каподастр подсказывается звёздочкой.
- Zen «в полосе»: ряд аккордов текущей секции, играющий залит, следующий обведён.
- Режим zen: автор задаёт по умолчанию, слушатель меняет, выбор слушателя хранится для песни.
- Zen открывается на паузе; во время игры тап — пауза; на паузе текст листается, тап по строке
  или аккорду — начать оттуда.

## Этапы

Одна спека, отдельные планы на этапы. Сначала доделывается alphaTex
(`docs/superpowers/plans/2026-09-27-alphatex-tabs.md`, задачи 7–10): этапы ниже правят те же
`song-view.tsx`, `zen-mode.tsx` и редактор, а пересчёт табов нельзя проверить, пока табы не
нарисованы.

- **A.** Строй песни, аппликатуры, названия аккордов, диаграмма, гриф, панель аккордов,
  аппликатуры автора, миграция.
- **D.** Вкладка «Аккорды».
- **B.** Каподастр слушателя и пересчёт в редакторе.
- **C.** Режимы zen, пауза, «играть отсюда».

## 1. Строй песни (этап A)

- Строи — гитарные из `packages/audio/src/tunings.ts`: `standard`, `drop-d`, `half-step-down`,
  `d-standard`, `drop-c`, `open-g`, `open-d`, `dadgad`.
- `songTuning(id)` → `{ id, strings, shift }`: `strings` — струны, по которым считаются формы и
  лады табов, `shift` — сдвиг звука в полутонах.
  - `half-step-down` → струны `standard`, `shift = −1`; `d-standard` → `standard`, `−2`;
    `drop-c` → `drop-d`, `−2`.
  - Остальные — свои струны, `shift = 0`; аккорды называются по реальному звучанию.
- Звук аккордов и табов: `midi = strings[i] + лад + каподастр + shift`. `scheduleNotes` и
  `scheduleTab` получают струны (сейчас там жёстко `OPEN_STRING_MIDI`), сдвиг складывается с
  каподастром.
- Табы alphaTex по-прежнему шестиструнные, `string 1` — самая тонкая.
- Строка деталей на странице песни показывает строй, если он не стандартный (`Drop D`);
  названия — из уже существующих переводов тюнера.

## 2. Аппликатуры (`packages/audio`, этап A)

- `voicingsFor(chord: string, strings: readonly number[], { limit = 8 })` → аппликатуры по
  возрастанию сложности. Аппликатура — лады от самой толстой струны к самой тонкой, `null` —
  струна не звучит (как `GuitarFrets` сейчас).
- Первой идёт форма из `CHORD_CATALOG`, если строй — стандартная сетка.
- Поиск — как в `searchVoicing`, но окна по ладам 0–12 и все подходящие формы, а не одна.
  Повторы убираются. Разнообразие: сначала лучшая форма для каждой позиции (самый низкий
  прижатый лад), затем остальные по сложности, до `limit`.
- Правила поиска от числа струн: звучащих струн минимум `min(4, струн − 1)`. В re-entrant строе
  (укулеле) бас не проверяется вовсе: ни корень, ни нота после `/` не обязаны быть самыми низкими.
- Сложность — та же оценка, что сейчас в `shapeCost` (разброс ладов, позиция, заглушённые и
  открытые струны), плюс признак баррэ. Экспортируется для подсказки каподастра.
- `voicingFor(chord)` (одна форма для звука) остаётся — первая из `voicingsFor` по строю песни.
  Звук песни берёт сначала аппликатуру автора, потом её.

## 3. Названия аккордов (`packages/chord-sheet`, этап A)

- `nameChord(midis: number[], { ignoreBass?: boolean })` → названия по убыванию правдоподобия:
  `['Am', 'C6/A']`.
- Корни-кандидаты — нажатые ноты. Интервалы от корня сверяются с таблицей качеств: мажор, `m`,
  `7`, `maj7`, `m7`, `dim`, `dim7`, `m7b5`, `aug`, `sus2`, `sus4`, `6`, `m6`, `9`, `add9`, `5`,
  `7sus4`. Квинта может отсутствовать у аккордов из четырёх и более нот.
- Бас — самая низкая нота; если это не корень — слэш-аккорд. Выше ранг у точного совпадения и у
  корня в басе.
- `ignoreBass` — для re-entrant строёв: слэш-аккордов не даём.
- Таблица качеств согласована с `chordTones`: для каждого качества
  `nameChord(ноты chordTones(X))` содержит `X`.

## 4. Диаграмма и гриф (web, этап A)

`features/chords/`:

- `<ChordDiagram frets name? size>` — SVG: струны, 5 ладов, порожек или номер первого лада,
  `x`/`o` над струнами, точки, баррэ. Номеров пальцев нет. Тап — звук аккорда.
- `<Fretboard strings frets onChange>` — вертикальный гриф на 12 ладов, струн — сколько в строе.
  Тап по ладу ставит ноту на струну (одна на струну), повторный тап снимает; тап над порожком
  переключает `o`/`x`. Используется в шторке аппликатур (A) и в определителе (D).

## 5. Панель аккордов на странице песни (этап A)

- Аккорды — `chordList(doc)` в порядке появления (после пересчёта под каподастр слушателя, этап B).
- Карточка: название, `<ChordDiagram>`, `‹ 2/6 ›`. Варианты: аппликатура автора (если есть),
  затем `voicingsFor` без повторов. Нет ни одной — «нет аппликатуры».
- Десктоп (≥1024px): колонка справа от текста, прилипает при прокрутке; «Скрыть» сворачивает её
  в узкий ярлык «Аккорды» у края.
- Телефон: полоска карточек под шапкой песни, листается вбок; сворачивается в строку.
- Свёрнута ли панель — одна настройка на устройстве для всех песен.
- Тап по аккорду в тексте страницы — всплывашка с той же карточкой. Пролистанный вариант общий
  для панели и всплывашки, пока страница открыта, и нигде не сохраняется.
- «Слушать» и звук разделов играют аппликатуры автора, а не пролистанные.

## 6. Аппликатуры автора в редакторе (этап A)

- Карточка деталей: «Строй» рядом с «Каподастр».
- Над песней в визуальном редакторе — та же полоска аккордов; тап по карточке открывает шторку
  аппликатур. В `ChordPalette` для уже поставленного аккорда — кнопка «Аппликатура», та же шторка.
- Шторка «Am»: сетка вариантов, тап — звук и выбор, на выбранном галочка. «Нарисовать свою» —
  `<Fretboard>`, под ним вживую `nameChord`: «Am ✓» или «Звучит как C6/A, а не Am»; сохранить
  можно и с предупреждением. «Как по умолчанию» убирает выбор.
- Аппликатуры относятся к строю и каподастру автора. При сохранении песни убираются аппликатуры
  аккордов, которых в песне нет.
- Смена строя в редакторе не пересчитывает аккорды и табы — они остаются как написаны. Аппликатуры
  автора при этом сбрасываются с подсказкой: те же лады в другом строе — другой аккорд.

## 7. Данные и API (этап A)

Миграция одна, таблица `arrangement`:

- `tuning text not null default 'standard'`;
- `voicings jsonb not null default '{}'` — `Record<string, (number | null)[]>`, ключ — аккорд,
  нормализованный как в `chordList` (`Hm` → `Bm`);
- `zen_mode text` — `'inline' | 'strip'`, `null` — авто (используется на этапе C).

`save-arrangement` (zod): строй из списка гитарных; не больше 64 аппликатур; ключ — `isChord`;
длина — число струн строя; лад — `null` или целое 0–24; хотя бы одна звучащая струна;
`zenMode` — одно из двух или `null`. Поля попадают в `ArrangementView`, черновик (`use-draft`) и
офлайн-копию (она хранит `ArrangementView` целиком).

## 8. Вкладка «Аккорды» (этап D)

- Навигация: Тюнер · Песни · Аккорды · Моё; маршрут `/[locale]/chords`, клиентская страница
  (работает и в статическом экспорте Capacitor).
- Сверху: «Определить / Найти»; инструмент и строй — общие с тюнером (`useTunerSettings`).
- «Определить»: `<Fretboard>` на струны выбранного строя. Рядом крупно название и 2–3
  альтернативы чипами, под ними ноты (`A C E`); тап по названию — звук; «Очистить».
  - Одна нота — её название; две — интервал или пауэр-аккорд (`E5`); три и больше — `nameChord`
    (`ignoreBass` для укулеле). Не подошло — «Не похоже на известный аккорд», ноты всё равно видны.
- «Найти»: поле ввода и чипы — ряд корней (C … B) и ряд качеств (—, m, 7, m7, maj7, sus4, …).
  Ниже — сетка `voicingsFor` под строй, до 12; тап — звук.
- Звук — тот же синтез, что в песнях.

## 9. Каподастр слушателя (этап B)

### Функции (`packages/chord-sheet`)

- `transposeChord(raw, semitones, spelling)` — корень и бас сдвигаются, суффикс как есть.
  `spelling` (`'sharp' | 'flat'`) — по песне: бемолей у автора больше, чем диезов, — бемоли.
  Если в песне есть `H`, си пишется `H`.
- `withCapo(doc, strings, from, to)` → `{ doc, unreachable }`:
  - аккорды сдвигаются на `from − to` полутонов;
  - ноты alphaTex: высота `strings[s] + from + лад`; на новом месте лад
    `высота − strings[s'] − to` должен быть 0–24. Сначала та же струна, потом соседние по
    близости, при равенстве — более толстая. Две ноты одного удара на одну струну не ставятся.
    Связанная нота (`tie`) идёт за своей. Не помещается — нота остаётся на своей струне с
    отрицательным ладом и `unreachable: true` (новое необязательное поле `TabNote`), звук
    прежний. Легато и слайд между нотами на разных струнах снимаются;
  - ASCII-табы (`type: 'tab'`) не меняются;
  - `unreachable` — сколько нот не поместилось.
- `capoHints(doc, strings, authorCapo)` — для ладов 0–7: суммарная сложность первых аппликатур
  аккордов после пересчёта и число баррэ. Одно-два лучших положения — ★, без баррэ — «без баррэ».

### Страница песни

- «Каподастр» в строке деталей — кнопка: список ладов 0–12 с отметкой «у автора», ★ и «без баррэ»,
  пункт «Как у автора». Выбор слушателя отличается от авторского — кнопка подсвечена.
- Текст, панель, табы, «Слушать» и zen получают `withCapo(...)` и выбранный каподастр. Аппликатуры
  автора действуют, только когда каподастр совпадает с авторским.
- `TabStaff` рисует `unreachable` красным `?`; над табом плашка «N нот не сыграть с каподастром на
  K-м ладу». Над ASCII-табом при чужом каподастре — «таб для каподастра N».

### Редактор

- В выборе каподастра — те же ★.
- Есть аккорды или табы, каподастр меняется → диалог «Пересчитать аккорды и табы под каподастр K?
  Звучание не изменится»: «Пересчитать» / «Оставить как написано».
- «Пересчитать» — `withCapo`; в исходнике alphaTex переписываются только числа «лад.струна» нот
  (парсер запоминает их место в тексте), остальной текст не трогается; аппликатуры автора
  сбрасываются с подсказкой. Если остаются недоступные ноты, диалог это пишет, и «Пересчитать»
  недоступна.

## 10. Zen (этап C)

### Яркость

По порядку строк на экране, в обоих режимах: текущая — 100% и лёгкое увеличение; следующая —
~75%; через одну — ~55%; дальше — 30%; пройденные — 15%.

### Режимы

- `inline` — аккорды над словами, как сейчас.
- `strip` — под шапкой закреплён ряд аккордов текущей секции в порядке первого появления
  (`Am F C G`): играющий залит, следующий обведён; при смене секции ряд меняется. Тап по ряду
  показывает/прячет мини-диаграммы (с аппликатурами автора и каподастром слушателя). В словах
  аккордов нет: место смены — точка под слогом, точка играющего аккорда горит. Табы — как есть.
- Режим: выбор слушателя для песни → `arrangement.zenMode` → авто (не больше 4 разных аккордов —
  `strip`, иначе `inline`). Чистая функция `resolveZenMode`.
- В редакторе в карточке деталей — «Zen по умолчанию: Авто / Над словами / Полоса».

### Пауза и «играть отсюда»

- Фазы: `ready → count → play ⇄ pause → count → play … → done`. `ready` — пауза в начале песни.
- «Сыграть» на странице открывает zen в `ready`. Панель паузы внизу: режим, скорость (`SpeedChips`
  из alphaTex-плана), каподастр, большая «Начать» (в `pause` — «Продолжить»), «Сначала».
- Во время игры тап по экрану или пробел — пауза; свёрнутое приложение — пауза, как сейчас.
- На паузе текст свободно листается пальцем и колесом. Тап по строке — начало строки; тап по
  аккорду (в `strip` — по точке) — этот аккорд. Место подсвечено. «Продолжить» → 3-2-1 → игра
  оттуда, прокрутка снова автоматическая.
- Время места — из `zenLines`: `start` строки или `chordStarts[k]`.

## Настройки на устройстве

- `chordtune.song.<arrangementId>` → `{ capo: number | null, zenMode: 'inline' | 'strip' | null }`,
  хук `useSongSettings(id)`.
- `chordtune.chords.panel` → `'open' | 'hidden'`.
- Как `useTunerSettings`: сначала значения по умолчанию (совпадает с пререндером), затем
  загрузка; нечитаемое или неверное значение — по умолчанию.

## Ошибки

- Нет аппликатуры — «нет аппликатуры» в карточке; песня играет как раньше (аккорд без формы
  молчит).
- Неверные `tuning`, `voicings`, `zenMode` — `BAD_REQUEST` от zod, в редакторе — текст ошибки, как
  у остальных полей.
- localStorage недоступен — настройки живут до перезагрузки.

## Тесты

- `voicingsFor`: стандарт, Drop D, Open G, DADGAD, укулеле; все тоны на месте, бас самый низкий
  (кроме укулеле), разные позиции среди первых вариантов, каталог первым только в стандарте.
- `songTuning`: сдвиги для полутона ниже, D Standard, Drop C.
- `nameChord`: обратная проверка через `chordTones` для всех корней и качеств; `x02210` → `Am`
  первым, `C6/A` среди вариантов; слэш-аккорды; `ignoreBass`.
- `transposeChord`: диезы, бемоли, `H`, слэш-аккорды, сдвиг через октаву.
- `withCapo`: переименование аккордов; перенос открытой ноты на толстую струну; `unreachable`
  на 6-й струне; коллизия в одном ударе; `tie`; звук (`midi` каждой ноты) не меняется; каподастр
  ниже авторского.
- `capoHints`: песня `F C Dm` без каподастра → ★ и «без баррэ» на 5-м (`C G Am`); на 3-м
  (`D A Bm`) «без баррэ» нет.
- Переписывание исходника alphaTex: меняются только числа нот, комментарии и пробелы на месте.
- `resolveZenMode`; позиция «играть отсюда» в `zen-timing`; ряд аккордов секции и следующий аккорд.
- `save-arrangement`: валидация новых полей (PGlite).
- `useSongSettings` / разбор настроек — неверные значения → по умолчанию.
- UI — проверка пользователем в браузере и на устройстве.

## Не входит

- Слушатель меняет строй.
- Панель аккордов для укулеле в песне; табы и каподастр для баса и укулеле.
- Номера пальцев на диаграммах.
- Аккорды с произвольными именами (`Am*`, `Riff`).
- Синхронизация настроек слушателя между устройствами.
- Смена тональности под голос (транспонирование звучания).
