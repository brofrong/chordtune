# Табы в alphaTex, локальный темп и скорость воспроизведения — дизайн

Дата: 2026-09-27.

## Цель

Дать автору писать в песне табы с длительностями, подписями и словами, а слушателю — менять
скорость всей песни.

- Табы пишутся в синтаксисе alphaTex (подмножество), парсер свой, в `packages/chord-sheet`.
- Табы — часть общего таймлайна: звучат через `guitar-synth`, прокручиваются в zen-режиме,
  аккорды после таба начинаются сразу за ним.
- Темп задаёт автор: темп трека (уже есть, поле `tempo`) + переопределение на секции или блоке таба.
- Скорость выбирает слушатель: множитель 0.5×–1.5× на всю песню.

Решения пользователя: свой парсер, а не alphaTab целиком; локальный темп действует только на свой
кусок (секцию или блок) и потом сам возвращается к темпу трека; в табах нужны и подписи над нотами
(`{txt}`), и слова под нотами (`\lyrics`); редактор — сначала текст alphaTex с живым превью,
визуальная сетка потом отдельной задачей; слушатель меняет не BPM, а скорость (×).

## 1. Синтаксис

### Темп секции

Необязательный суффикс заголовка после ритма:

```
[Соло] @B 140bpm
[Бридж] 72bpm
```

Диапазон 30–300, как у темпа трека. Действует только на эту секцию. Вне диапазона —
предупреждение, темп игнорируется.

### Блок alphaTex

Новый блок, отдельный от `{start_of_tab}`:

```
[Проигрыш]
{start_of_alphatex}
\tempo 140
\ts 4 4
\lyrics "Я за-бу-ду твоё и-мя"
:8 0.5 5.3 8.2 0.5 5.3 5.2 0.5 5.3 |
   6.2{txt "тише"} 0.5 5.3 5.2 r.4 (0.5 2.4).4
{end_of_alphatex}
```

`{start_of_tab}` не трогаем: там ASCII-табы из импорта «аккорды над текстом», они по-прежнему
показываются моноширинным текстом и не занимают времени.

Темп блока: `\tempo` блока → темп секции → темп трека. После блока темп возвращается сам.

### Поддерживаемое подмножество

Метаданные (в начале блока, до первой доли):

- `\tempo N` — 30–300.
- `\ts N M` — размер; по умолчанию 4/4.
- `\lyrics "…"` — слоги разделяются пробелом или `-`; `_` — пропустить долю.

Доли:

- Нота `лад.струна` (лад 0–24, струна 1–6, 1 — верхняя ми).
- Длительность: `.N` после ноты/доли — только для неё; `:N` — для всех следующих долей.
  N ∈ {1, 2, 4, 8, 16, 32}. По умолчанию `:4`.
- Пауза `r`, аккорд `(0.5 2.4)`, мёртвая нота `x.3`, лига `-.3` (продление ноты на струне 3
  из предыдущей доли, без новой атаки).
- Эффекты в `{…}` через пробел, у ноты (внутри аккорда — у конкретной ноты) или у доли (после
  `)`/длительности): `d` — точка, `tu 3` — триоль (также `tu 5`, `tu 6`), `h` — hammer-on/pull-off
  к следующей ноте, `sl` — слайд к следующей ноте, `b (0 4)` — бенд (четверти тона), `v` — вибрато,
  `pm` — палм-мьют, `lr` — let ring, `txt "…"` — подпись над долей.

Структура:

- `|` — такт. Последний `|` необязателен.
- `\ro` в начале такта — начало репризы, `\rc N` в начале такта — конец репризы после этого
  такта, всего N проигрываний. Вложенные репризы не поддерживаются (ошибка).

Слоги `\lyrics` раскладываются по долям по порядку, пропуская паузы и доли, где все ноты — лиги.
Лишние слоги — предупреждение, недостающие — просто пусто.

Ошибки и неизвестные команды/эффекты — `Diagnostic` с номером строки и колонки в исходнике песни
(как у `parse()`), разбор продолжается. Незаполненный такт (меньше долей, чем в размере) —
предупреждение, такт звучит той длины, что есть; переполненный — предупреждение, такт не режем.

## 2. Модель и время (`packages/chord-sheet`)

Новые типы:

```ts
type TabNote = { string: number; fret: number | 'x'; tie: boolean; effects: NoteEffects };
type TabBeat = {
  /** Длина в четвертях с учётом точки и триоли. */
  quarters: number;
  duration: 1 | 2 | 4 | 8 | 16 | 32;
  dotted: boolean;
  tuplet: number | null;
  notes: TabNote[]; // пусто — пауза
  text: string | null;
  syllable: string | null;
  palmMute: boolean;
  letRing: boolean;
};
type TabBar = { beats: TabBeat[]; repeatOpen: boolean; repeatClose: number | null };
type TabBlock = {
  tempo: number | null;
  time: [number, number];
  /** Как написано — для отрисовки со знаками репризы. */
  bars: TabBar[];
  /** Развёрнутые репризы — для времени и звука; индексы в `bars`. */
  playOrder: number[];
};
```

- `Line` получает третий вариант: `{ type: 'alphatex'; source: string[]; block: TabBlock }`.
- `Section` получает `tempo: number | null`.
- `parseAlphaTex(lines, firstLineNo)` → `{ block, diagnostics }`; вызывается из `parse()`.
- `serialize()` пишет исходник блока как есть и суффикс `NNNbpm` в заголовке.
  `chords-over-lyrics` сериализует блок так же.

Таймлайн:

- `TimelineEvent` становится объединением: аккордовое событие (как сейчас, `kind: 'chord'`) и
  `{ kind: 'tab'; block; section; line; start; length }`, где `length` — длина блока в тактах
  его размера по `playOrder`.
- У обоих видов `tempo: number | null` — `\tempo` блока ?? темп секции ?? `null`.
- `${xN}` и прочие маркеры строк на блок не действуют; ритм `@X` блок не меняет.
- `eventSeconds(events, rhythms, bpm)` — по-прежнему единственное место, где такты
  превращаются в секунды: `event.tempo ?? bpm`; аккорды — по размеру ритма, таб — сумма `quarters`
  долей по `playOrder` × 60 / темп.
- `tabBeatSeconds(block, bpm)` — начало каждой доли по `playOrder` (для звука, курсора и zen).

## 3. Скорость ×

- Скорость — множитель поверх готового расписания: все времена делятся на `speed`. Парсер,
  таймлайн и темп о ней не знают.
- Шаги: 0.5, 0.75, 1, 1.25, 1.5. Хранится в памяти сессии (общий стор для дока и zen),
  при открытии песни — 1×.
- Док песни: переключатель чипами; действует на Listen, «сыграть секцию», паттерн ритма и блок таба.
  Подпись: `Бой A · 90 BPM · 0.75×` (множитель — только если не 1×).
- Zen: переключатель скорости вместо ±5 BPM. При смене позиция сохраняется:
  `time = time * oldSpeed / newSpeed`.

## 4. Звук (`packages/audio`)

- `scheduleTab(block, { bpm, capo })` → `ScheduledNote[]` (тот же тип, что у ритмов).
  Высота: `OPEN_STRING_MIDI[string] + fret + capo`; строй стандартный.
- `scheduleNotes` для событий `kind: 'tab'` вызывает `scheduleTab` со сдвигом на начало события.
- Звучат: ноты, паузы, аккорды, лиги (без новой атаки), мёртвые ноты (`muted`), палм-мьют
  (тише и `muted`), let ring. Hammer/pull — нота с тихой атакой. Слайд, бенд, вибрато — обычная
  нота, только отрисовка.

## 5. Отрисовка: `TabStaff` (web, SVG)

- 6 линий, номера ладов; горизонтальный шаг доли пропорционален `quarters` с минимальной шириной
  под номер лада.
- Под табом — ритм: штили, вязки для 8/16/32, точки, цифра триоли; пауза — знак паузы.
- Над долями — `txt`, P.M. (с линией на серию), let ring. Техники: дуга h/p, косая линия слайда,
  стрелка бенда с подписью (½, full), волна вибрато, `x` для мёртвых нот.
- Под табом — слоги `\lyrics`.
- Такты переносятся по строкам под ширину контейнера; знаки репризы и `×N` у закрывающей черты.
- Проп `activeBeat` подсвечивает текущую долю; цвета — токены дизайн-системы, обе темы.

## 6. Страница песни и zen

- Страница песни: блоки alphaTex рисуются `TabStaff`; Listen и «сыграть секцию» включают табы;
  текущая доля подсвечивается.
- Zen: блок — одна zen-строка с временами долей из `tabBeatSeconds`; когда время внутри блока,
  прокрутка ведёт к строке `TabStaff` с текущей долей, доля подсвечивается.

## 7. Редактор

Визуальный:

- В шапке секции рядом с ритмом — чип темпа: пустой показывает «темп трека» блёкло; по нажатию —
  поле числа 30–300 и «сбросить». Пишет `Section.tempo`.
- В секции кнопка «+ Таб» вставляет пустой блок alphaTex (`insertLine`).
- Блок в ленте — отрисованный `TabStaff` с кнопками ▶ (только этот блок, текущие темп и скорость)
  и ✎.
- ✎ открывает шторку (по образцу `rhythm-editor-sheet`): textarea с alphaTex (моноширинный,
  без автокоррекции и автозамены), под ней живое превью `TabStaff` и список диагностик с номерами
  строк; сверху поля темпа и размера, которые правят `\tempo`/`\ts` в начале блока; ▶ играет
  черновик; свёрнутая шпаргалка с примерами синтаксиса; «Готово» / «Отмена».

Текстовый: блок пишется как есть; диагностики подсвечиваются как у аккордов.

## 8. Импорт из Obsidian

`jtab`-блоки конвертируются в alphaTex: `$S F` → `F.S`; если во всех тактах блока одинаковое
число нот N ∈ {1, 2, 4, 8, 16}, блок становится `:N` в 4/4 и попадает в текст песни. Место —
по предшествующему `**Заголовку**`: в конец первой секции с таким же названием (без учёта
регистра), а если такой нет — новой секцией в конце песни. Иначе блок остаётся в заметках, как
сейчас.

## 9. Тесты

- Парсер: проигрыш пользователя как фикстура; длительности `.N` и `:N`; точка, триоль; аккорд;
  пауза; мёртвая нота; лига; эффекты; `txt`; `\lyrics` с `_` и пропуском пауз; репризы и
  `playOrder`; ошибки с правильными line/col; никогда не бросает.
- Заголовок: `140bpm` с ритмом и без, вне диапазона; сериализация туда-обратно.
- Таймлайн/время: темп секции, `\tempo` блока, возврат к темпу трека, аккорды после таба,
  размер 3/4 в блоке.
- `scheduleTab`: высоты с каподастром, лиги без атаки, мёртвые ноты и палм-мьют `muted`.
- Скорость: деление времён, сохранение позиции в zen.
- Импорт jtab: ровный блок конвертируется, неровный остаётся в заметках.
- UI проверяет пользователь сам.

## Не входит

Визуальный сеточный редактор таба; звук слайдов, бендов и вибрато; свой строй (`\tuning`);
многодорожечность и нотный стан; переиспользование рифов по ключу; конвертация ASCII
`{start_of_tab}` в alphaTex; сохранение скорости между сессиями.
